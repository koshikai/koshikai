# koshikai

大学院の修士課程で、強化学習を使ったブーリアンネットワークの制御を研究しています。個人開発では Web アプリを企画・実装し、自宅のサーバーで運用しています。

[ポートフォリオ](https://koshikai.dev)に、作品やサーバーの構成、研究の詳細をまとめています。[サイトのソースコード](https://github.com/koshikai/portfolio)も公開しています。

## 作品

- [Smoke it.](https://smoke-it.koshikai.dev) — 画面上の箱から 1 本ずつ取り出して喫煙を記録する Web アプリ。記録をもとに AI コーチに相談できます。
- [KariGallery](https://gallery.koshikai.dev) — イラストを展示・管理するギャラリー。決済機能を無効にしたデモを公開しています。
- [Turbo Circuit](https://github.com/koshikai/TurboCircuit) — ドリフトとアイテムで競う 3D カートレースゲーム。7 コースを収録し、画面分割とオンライン対戦に対応しています。[Windows 64-bit 版](https://github.com/koshikai/TurboCircuit/releases/latest)

## 研究

卒業研究では、ブーリアンネットワークのつながりを一時的に切り、目標の状態へ導く方法を調べました。[エッジ除去制御のコード](https://github.com/koshikai/bn-edge-removal-public)を公開しています。モデル間で制御の知識を移す方法も検討してきました。
