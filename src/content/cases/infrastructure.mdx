## 背景

自宅内での多岐にわたるサービス運用を整理し、最新技術を検証するための実験場としてのインフラ構築を目指しました。

## 課題

- 多様なサービス（Nginx, DNS, DB, 監視）の効率的かつ安全な共存
- 単一ノードでは限界のある機械学習タスク（画像分類等）の処理能力
- 頻繁な設定変更や配布に伴う運用コストの増大

## 判断

Proxmox VE と LXC によるマイクロサービス化、および GPU オフロードによる分散構成を選択しました。

## 実装

- **Proxmox VE + LXC:** 10以上のコンテナを展開し、Nginx Proxy Manager や AdGuard Home 等を体系的に運用
- **GPU オフロード:** Windows 側の NVIDIA GPU を Docker パススルーで活用し、Immich の顔認識・CLIP 処理をネットワーク越しに分散
- **IaC/DX 整備:** PowerShell による API 監視や、AI エージェント用の MCP サーバー設定の自動同期・配布スクリプトを構築

## 結果

重い機械学習タスクをメインマシンの GPU へ逃がすことで、低消費電力な Proxmox 上でも快適なセルフホスト環境を実現。また、AI エージェントとの連携が強化され、運用の自動化率が大幅に向上しました。

## 学び

特定のリソース（GPU等）を必要とするタスクを、ネットワーク越しに別ノードへオフロードする分散設計の有用性を実証できました。
