## 背景

実用的な SaaS (Software as a Service) としての機能を網羅したギャラリーアプリケーションの開発を目指しました。

## 課題

- 認証・決済を組み合わせたフルスタックな機能の実装
- 大容量になりがちな画像アップロードによるユーザー負荷
- 直感的で滑らかな画像閲覧体験の構築

## 判断

Next.js (v16.2), Prisma (v7.7), Auth.js, Stripe を採用し、クライアント側の画像処理を組み込むことにしました。

## 実装

- **フルスタック基盤:** Auth.js による認証と Stripe API による決済機能の統合
- **画像最適化:** `browser-image-compression` によるアップロード時の軽量化
- **リッチな操作:** `react-zoom-pan-pinch` によるズーム・パン、Framer Motion による洗練されたアニメーション
- **型安全な DB 運用:** Prisma v7.7 と PostgreSQL による堅牢なデータ設計

## 結果

認証から決済、アップロードまでの全フローをスムーズに提供し、最新の Web 機能を統合した商用レベルの基盤が完成しました。

## 学び

外部サービス (Auth.js, Stripe) との API 連携において、堅牢なデータモデルを設計する重要性を学びました。
