## 背景

禁煙・減煙を目指すユーザー向けに、ネイティブアプリのような操作感を提供する PWA (Progressive Web App) として開発しました。

## 課題

- Web アプリ特有の読み込み待ちや、オフライン時の操作性への不安
- 単調になりがちな記録作業のモチベーション維持
- モバイル端末での使い勝手の追求

## 判断

Next.js (v16.2), Prisma, NextAuth を軸に、Framer Motion や Recharts を用いた高度なフロントエンド実装を決定。

## 実装

- **ネイティブ級の UI/UX:** Glassmorphism、Safe Area 管理、Fluid Typography を徹底した設計
- **オフライン対応と Optimistic UI:** 通信断でも機能し、操作に対し即座に UI を更新する楽観的 UI を採用
- **データ可視化:** Recharts を用い、記録を視覚的にフィードバック
- **堅牢性向上:** Jest / React Testing Library による網羅的なテスト体制

## 結果

オフライン環境でも動作する信頼性と、スムーズなアニメーションによる高いユーザー体験を両立しました。

## 学び

Optimistic UI の導入により、Web とネイティブの境界を曖昧にする重要性を再認識しました。

## 次の改善

- AI による禁煙アドバイス生成
