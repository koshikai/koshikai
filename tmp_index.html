Case Studies

自宅内写真管理の分散化

課題: 単一の NAS 故障による全データの消失リスクと、家族全員での共有漏れ。

対応: Proxmox + Docker で Immich を構築。ストレージは ZFS ミラーで冗長化し、バックアップを自動化。

結果: 家族全員がどこからでも写真をアップロード可能になり、データ消失リスクを最小化。

詳細を見る

禁煙支援 PWA の開発

課題: 既存の禁煙アプリが複雑すぎたり、オフライン時の挙動が不安定だったりした。

対応: Next.js と PWA を組み合わせ、オフライン優先の UI を構築。グラフによる可視化を統合。

結果: 自身の禁煙継続に成功し、軽量かつ信頼性の高いツールとしての実用性を証明。

詳細を見る

イラスト管理 SaaS への移行

課題: 散らばったイラスト資産を、一箇所で管理しつつ決済や公開まで行いたい。

対応: Prisma v7 と Auth.js で基盤を刷新。Stripe と連携し、安全な課金フローを実装。

結果: アセットのアップロードから公開、販売までが一元管理可能になった。
